# Paperdoll: product one-pager

**What it is:** Build a pixel character and take it across Neorgon. A 16x16 character builder over the shared Neorgon Avatar Kit: kinds, hair, outfits, hats, held items, pets, colours, with rare parts that unlock by doing things.

**Who it is for:** Anyone who uses a Neorgon tool that draws people (Floorplan first) and wants the little person on the board to be theirs, plus anyone who likes dressing up a pixel character for five minutes.

**Register:** product (a tool someone uses), not brand (a page someone visits).

**The scene:** A laptop, a spare five minutes between meetings, a Floorplan tab open next door. Dark theme, the character large and centred, parts one click away; the joy is in the tile grid and the secrets panel, not in a long form.

**What done looks like:** A named character saved as "mine" in the Neorgon cookie, so Floorplan offers it on the next visit, and a code on the clipboard to paste anywhere else.
