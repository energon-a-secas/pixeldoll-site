# CLAUDE.md: Paperdoll

Pixel character builder over the shared Neorgon Avatar Kit: nine slots, 62 parts, colours,
rare parts behind unlocks, and a "my character" cookie that other sites (Floorplan) read.

**Live:** paperdoll.neorgon.com · **Port:** 8869

## Run

```bash
make serve
```

Then open http://localhost:8869. ES modules, so `file://` does not work. No dependencies.

## Architecture

| Module | Owns |
|---|---|
| `js/neorgon-avatar.js` | **vendored** Neorgon Avatar Kit (canonical `packages/neorgon-ui/avatar/avatar.js`): catalog, drawing, codes, cookies. Never edit here; `packages/neorgon-ui/sync-avatar.sh` |
| `js/state.js` | the draft (`spec`, `name`, `savedAt`) in localStorage `paperdoll-v1`; `saveMyCharacter()` writes the `neo_character` cookie through the kit |
| `js/wardrobe.js` | unlock ids, hints and triggers (shuffle streak, named save, Konami, three code words); `grant()` writes `neo_unlocks` |
| `js/render.js` | hero canvas at 8x, the sizes row (64/32/16), tabs, tiles drawn as the current character wearing each part, colour rows, actions, secrets |
| `js/events.js` | delegated clicks/inputs/keys; `celebrate()` opens the secrets panel on a fresh unlock |
| `js/export.js` | code, `#c=` link, PNG download, `fromUrl()` |

## Conventions

- Rendering never gates: a locked part still draws if a spec carries it (shared links, Floorplan). Only tile clicks refuse, and they open Secrets with the hint.
- Sprites are drawn at 1x and scaled by CSS to 16/32/48/64; the hero is a canvas at scale 8. Any non-integer scale blurs.
- The draft and "my character" are different things: the draft is this tab's work in progress; "mine" is what the fleet sees. `isMine()` compares codes.

## Gotchas

- A `#c=` link over an existing draft does not overwrite it: a bar offers "Edit it" or "Keep mine". With no draft, the link becomes the draft.
- Cookies are host-only on localhost and `Domain=.neorgon.com` live, so the cross-site flow only shows on the real domain.
- The Konami listener ignores keys typed into inputs; the secret field takes words (`neorgon`, `boo`, `ufo`, or the spelled-out Konami sequence).

## Do not touch

- `js/neorgon-*.js` and `css/neorgon-*.css`: vendored kits, regenerated by `packages/neorgon-ui/sync-*.sh`.
